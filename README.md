# 星系（Galaxies）

> 把棋盘划分成若干区域：每个区域恰好包含一个圆点，并且关于该圆点 **180° 旋转对称**。

本项目是「星系 / Galaxies / Tentai Show」逻辑谜题的完整实现：实时校验、错误高亮、
回溯求解、提示一格、逻辑解题回放、自定义题板（保存 / 编辑 / 删除）与 18 道内置题。

开发服务器端口：**5217**（`package.json` → `puzzle.port`）。

---

## 规则

1. 棋盘上给出若干圆点，圆点位于**格子中心**或**格线交点**上。
2. 把棋盘划分成若干区域，每个区域**恰好包含一个圆点**。
3. 每个区域必须关于自己的圆点呈 **180° 旋转对称**（旋转后形状与格子集合完全重合）。
4. 所有格子都要被覆盖，区域互不重叠；题目唯一解。

关于圆点位置：格心圆点所在区域大小必为奇数；格点圆点（位于格线交点）会强制其周围
2×2 四格同属一个区域，区域大小必为偶数。

## 操作

| 操作 | 说明 |
| ---- | ---- |
| 鼠标左键拖拽 | 沿格子之间的边连续画区域边界（一笔画/擦：按下时决定这一笔是画还是擦） |
| 鼠标右键 | 擦除鼠标下那条边界 |
| 方向键 | 移动键盘光标（棋盘上会显示虚线框） |
| 空格 / 回车 | 切换「光标刚跨过的那条边」：画上或擦掉边界 |
| 中键 / 在空白处拖拽 | 平移画布 |
| 滚轮 / `+` `-` `0` | 缩放 / 缩放 / 复位 |
| `Z` / `Shift+Z` | 撤销 / 重做 |
| `C` | 检查 |
| `L` | 逻辑解题 / 停止回放 |
| `P` | 暂停 / 继续回放 |
| `R` | 随机抽题 |
| `M` | 音效开关 |
| `Esc` | 清空当前盘面 |

画上边界时播放「拨弦」音并让边界线振动，擦除时播放水滴音；逻辑回放会逐帧高亮。

## 校验与错误高亮

每次落子后自动实时校验（不需要点「检查」）：

- **红色错误**：含一个圆点但不对称的区域；被边界切开的圆点（锚定格落在不同区域）。
- **橙色虚线提示**：还没有圆点、或圆点多于一个的区域（继续画边界即可）。
- 盘面一条边界都没画时不标错误，状态栏提示「开始画区域边界」，避免开局整盘爆红。
- 状态栏给出当前进度：`x/y 个区域已正确`、`n 个区域不对称`、`n 个圆点落在边界上` 等。

每个连通区域用不同底色（相邻区域贪心配色不同），玩家画的边界是深墨粗线，圆点是黑点；
这些视觉元素一起构成直观的区域可视化。

## 求解器与逻辑解题

- **回溯求解器**（`src/game/solver.ts`）：把「每个格子属于哪个圆点」当变量，约束为
  对称配对、圆点锚定格、区域连通性；带单值域传播、连通性剪枝、MRV 分支。
  支持最多枚举 2 个解 → 用于「显示解」与**自定义题唯一解校验**。
- **逻辑解题**（`src/game/logic.ts`）：纯规则推理 + 反证试探，产出
  `LogicPlan` / `PlaybackFrame` 回放；每推出一条确定的边界生成一帧，播放时逐帧画线。
  规则推不动时（例如玩家已画了边界、或自定义难题）退回回溯补齐并标记未饱和。
- **提示一格**：对比当前盘面与参考解，翻转第一处不同的边界。

## 自定义题板

侧栏「自定义」按钮打开通用编辑器（cell 模式）：

1. 输入宽高（4–20，建议不超过 20×20），点「生成网格」；
2. 鼠标点击格子放/去圆点（数字键 `1` 放圆点，`0`/`Backspace`/`Delete` 清空，方向键移动光标）；
3. 「载入题板」：按圆点生成题目、写入题库并立即开始玩；
4. 「保存到题库」：保存当前题面（再次保存会更新同一条）；
5. 「求解」：回溯求解并填入一解，同时提示题面是否唯一解；
6. 题库列表里的「编辑」把已保存的题读回编辑器（保存覆盖原题）；
7. 题库列表里的「×」两次点击确认删除。

加载/保存自定义题时会自动做唯一性校验（盘面 ≤ 12×12 时），并在状态栏/编辑器提示
「唯一解 ✓」或「题面有多解 / 无解」。

## 内置题库

`src/game/puzzles-data.ts` 由生成器 `npm run gen` 生成，共 **18 道**，全部：

- 参考解通过规则校验；
- **唯一解**（求解器最多找 2 个解，确认只有 1 个）；
- **可纯逻辑推完**（逻辑解题器不依赖回溯即可解出并回放）。

生成器（`src/game/generator.ts`）采用「随机对称矩形拼铺」：随机切分出奇数×奇数
（格心圆点）或偶数×偶数（格点圆点）的矩形，矩形天然满足 180° 对称、连通、恰一圆点，
因此必定是一份合法解；再过滤唯一解 + 逻辑可解。`npm run check` 会独立复核以上所有性质。

## 启动 / 构建 / 测试

```bash
npm install
npm start        # 开发服务器 http://127.0.0.1:5217/（自动打开浏览器）
npm run dev      # 只启动 vite（不自动打开）
npm run build    # tsc --noEmit + vite build
npm run check    # 题库深度审计（唯一解 / 逻辑可解 / 序列化 / 自定义编解码）
npm run ui-check # Playwright（Edge）冒烟验证：内置题 / 鼠标 / 键盘 / 自定义题增删改
npm run gen      # 重新生成内置题库（会重写 src/game/puzzles-data.ts）
```

`npm run ui-check` 依赖本机 Microsoft Edge（默认路径
`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`，可用 `EDGE_PATH` 覆盖），
需要先启动 5217 端口服务；截图输出到 `output/playwright/`。

## 已知限制

- 内置题是由「对称矩形拼铺」构造的：区域形状都是矩形（规则完全正确，但视觉上比手绘
  星系更规整）；生成器只用唯一解 + 逻辑可解作为质量门槛。
- 自定义题板使用 cell 模式，只支持**格心圆点**；含格点圆点的内置题不能在编辑器里编辑。
- 自定义题唯一性校验在盘面 ≤ 12×12 时自动进行，更大的盘面会跳过（求解可能较慢）。
- 求解器搜索节点上限内无解时会报告「超时」，可先用「逻辑解题」再求解。

## 图片导入

`npm run import-image -- <图片路径>` 可以自动识别星系（Galaxies）题图：先找粗黑外框和灰色网格线，再挑出近正方形的圆环，按半格坐标生成 `dots` 编码。

```bash
npm run import-image -- 题图.png --dry                 # 只识别与预览
npm run import-image -- 题图.png --name "我的星系" --append   # 追加到题库
npm run import-image -- 题图.png --append --verify      # 额外做唯一解检查（大图会超时警告）
```

| 参数 | 说明 |
|------|------|
| `--size N` / `--width W --height H` | 覆盖棋盘尺寸 |
| `--name` / `--id` | 题库名字 / id |
| `--append` / `--verify` / `--dry` | 写入题库 / 唯一解检查 / 只识别 |

说明：职业大题会出现「格点、格心、边中点」三类圆点，项目已支持边中点圆点；超过 36 个圆点的导入题可以正常游玩，但没有「显示解」参考解（参考解是 base36 编码）。
